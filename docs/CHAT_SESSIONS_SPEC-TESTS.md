- **Relevant Endpoints, Functions, and Behaviors**:
  - **REST Endpoints** ([`ChatSessionsController`](../src/chat-sessions/chat-sessions.controller.ts)):
    - `GET /api/v1/chat-sessions` (`list` — cursor pagination with fixed page size `10`, `has_more`, `next_cursor`, empty state `items: []`, boundary `10` limit, case-insensitive `?q=` search, ReDoS/NoSQL injection resistance, excluding `deleted_at !== null` and `message_count === 0`).
    - `GET /api/v1/chat-sessions/:id` (`get` — session metadata + ordered messages with assistant RAG metadata, 401 unauthenticated, 404 unauthorized/soft-deleted).
    - `PATCH /api/v1/chat-sessions/:id` (`rename` — updates `title` and `updated_at` while preserving `last_message_at`, 401 unauthenticated, 404 unauthorized/soft-deleted).
    - `DELETE /api/v1/chat-sessions/:id` (`remove` — idempotent cascaded soft delete setting `deleted_at` on `chat_sessions` and `chat_messages`, 401 unauthenticated).
    - Absence of `POST /api/v1/chat-sessions` (sessions are created lazily on the first message exchange).

    - `validTitle(raw)`, `formatTimestampTitle(date)`, `escapeRegex(s)`, `isTransactionUnsupported(e)`.

    - `assertOwned(sessionId, userId)`.
